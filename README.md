This fork adds a Yara view module to GView, enabling visualization of Yara rules and scan results.
Developed as part of a two-person team project for reverse engineering.
Members: Carcea Diana, Carcea Răzvan

Changes include:
- Added a Yara view window in the main interface
- Integrated Yara scanning functionality
